## 🎯 项目愿景

打造高性能、生产就绪的 AI Agent 记忆管理系统，支持 100,000+ 并发用户，提供完整的 3-Tier 记忆架构。

## 🚧 待实现功能

### FAQ 系统增强

**目标**: 完善高频问答自动上升机制

**功能**:
- [ ] **热度追踪** - 在 Qdrant payload 中添加 `access_count`, `heat_score`，每次检索时更新访问计数
- [ ] **自动提升** - 后台任务扫描候选 FAQ（访问≥10次，热度≥50），自动更新 `type` 字段为 "faq"
- [ ] **Wiki 导出** - 定时导出成熟 FAQ（30天+）到 Markdown，推送到 S3/OSS/Confluence

**优先级**: 高  
**预计完成**: 2026-03-01  
**详细文档**: [FAQ_SYSTEM.md](./FAQ_SYSTEM.md)
